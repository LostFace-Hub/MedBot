## 🌟 Overview

**Medora** is a full-stack AI-powered healthcare platform designed to simplify and modernize healthcare access.

It integrates:

* 📱 Android App (Kotlin)
* 🖥️ Backend API (Node.js)
* 📊 Dashboard (React)
* 🤖 AI Assistant (Next.js)

📌 It solves major healthcare issues like:

* Delayed consultations
* Fragmented medical records
* Lack of real-time monitoring
* Limited accessibility

👉 Medora creates a **single unified digital healthcare ecosystem**.

## ✨ Features

### 👤 User Management

* Secure Login & Registration (OTP)
* JWT Authentication
* Profile Management

### 👨‍⚕️ Doctor Services

* Browse doctors by specialization
* Book appointments
* Ratings & reviews

### 📅 Appointments

* Real-time slot booking
* Reschedule / Cancel
* History tracking

### 💊 Pharmacy

* Browse medicines
* Add to cart
* Order tracking

### 🏥 Health Tracking

* Heart rate, BP, steps
* Reports & analytics
* AI-based insights

### 🚨 Emergency

* SOS (112, 102)
* Hospital locator

### 🤖 AI Features

* Symptom checker
* Health assistant chatbot
* Personalized recommendations

## 🏗️ System Architecture

```
Mobile App (Kotlin)
        ↓
Backend API (Node.js / Express)
        ↓
MongoDB Database
        ↓
Dashboard (React) + AI (Next.js)
```

✔ Clean modular architecture
✔ Scalable backend
✔ Secure authentication

---

## 🔄 Data Flow

```
User → Mobile App → API → Database → Response → UI Update
```

* Retrofit handles API calls
* JWT secures requests
* MongoDB stores structured health data
